## Designing with AI
I like designing with AI! After trying many, many tools, I've found the most value in using Claude Code to create PRs. I have merged dozens of PRs to update this portfolio website. More to come soon, but for now, here's a link to the GitHub repo that shows how I've been working! 

[Portfolio GitHub Repo](https://github.com/shannonbux/shannon-soper-portfolio/pulls?q=is%3Apr+is%3Aclosed) 

## Basic learnings
Claude Code does well at the following:
- empowering me to implement ideas that require engineering expertise
- synthesizing coding and design best practices 
- auditing existing code to find things to improve

I do well at the following:
- discovering and asserting priorities, e.g. what even deserves attention or needs to be worked on?
- generating a coherent, tasteful UI/UX vision 
- writing with a human personality
